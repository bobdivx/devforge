# Wiki DevForge

Source des pages publiées sur **https://github.com/bobdivx/devforge/wiki**.

`Home.md` est la page d’accueil. `_Sidebar.md` / `_Footer.md` sont les éléments GitHub Wiki.

Le workflow `.github/workflows/wiki.yml` synchronise ce dossier vers `devforge.wiki.git` à chaque push sur `main`.
